1. WEB SCRAPING AND DATA EXTRACTION
   - Learned: BeautifulSoup4 for HTML parsing and web scraping
   - Key Insights:
     * Google News structure changes frequently, requiring multiple selectors
     * Rate limiting is crucial to avoid IP blocking
     * Different news sources have varying HTML structures
     * RSS feeds provide more reliable data than web scraping
   - Challenges Faced:
     * Google News frequently changes their HTML structure
     * Some sources block automated requests
     * Inconsistent data formats across different sources
     * Legal and ethical considerations for web scraping
   - Solutions Applied:
     * Implemented multiple selector strategies for robustness
     * Added respectful rate limiting and user agent rotation
     * Created fallback mechanisms using RSS feeds
     * Implemented comprehensive error handling

ISSUES FACED AND SOLUTIONS:
===========================

1. GOOGLE NEWS SCRAPING INSTABILITY
   - Issue: Google News frequently changes HTML structure
   - Root Cause: Dynamic website updates and anti-bot measures
   - Solution: Implemented multiple selector strategies and RSS fallbacks
   - Learning: Web scraping requires robust fallback mechanisms

2. MODEL LOADING PERFORMANCE
   - Issue: AI models take significant time to load
   - Root Cause: Large model files and initialization overhead
   - Solution: Implemented model caching with Streamlit decorators
   - Learning: Caching is essential for AI model performance

3. REAL-TIME UPDATE CHALLENGES
   - Issue: Balancing real-time updates with performance
   - Root Cause: Frequent updates can overwhelm the system
   - Solution: Implemented intelligent update scheduling and caching
   - Learning: Real-time systems require careful performance management

4. DATA QUALITY INCONSISTENCIES
   - Issue: Scraped data varies in quality and format
   - Root Cause: Different sources have varying data structures
   - Solution: Implemented comprehensive data validation and cleaning
   - Learning: Data quality is crucial for reliable applications

5. MEMORY MANAGEMENT ISSUES
   - Issue: Large datasets cause memory overflow
   - Root Cause: Inefficient data structures and caching
   - Solution: Optimized data structures and implemented memory monitoring
   - Learning: Memory management is critical for data-intensive applications
