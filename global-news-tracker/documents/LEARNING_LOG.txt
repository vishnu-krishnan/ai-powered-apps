ADVANCED PATTERNS DISCOVERED:

1. SESSION STATE CLEARING PATTERN
   ```python
   # Clear all session state variables
   keys_to_clear = list(st.session_state.keys())
   for key in keys_to_clear:
       del st.session_state[key]
   
   # Clear Streamlit caches
   st.cache_data.clear()
   st.cache_resource.clear()
   ```

2. SEARCH INPUT CLEARING PATTERN
   ```python
   # Clear search input when using buttons
   if 'main_search_input' in st.session_state:
       del st.session_state.main_search_input
   ```
